## understanding units

1. pixel- fixed size
2. percentage % - depends on parent 
3. vw - viewport width (depending on screen width )
4. vh - viewport height (depending on screen height)
5. vmax (viewport maximum) - depends on maximum viewport
6. vmim (viewport minimum ) depends on minimum viewport
7. em - according to the parent and can be cintrolled by parent 
8. rem- according to the root and can be controlled by root ( 1rem = 16px )
9. ch - width 10 ch then it will fit 10 characters in a line
10. lh- margin-top 2lh then it will take space of two lines
